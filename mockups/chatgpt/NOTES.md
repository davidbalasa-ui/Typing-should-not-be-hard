# TypeBetter settings

[View the phone design](phone-preview.svg) or download [the interactive mockup](settings-mockup.html).

The home screen opens with “silos” in a live keyboard preview. The suggestion strip offers “Xylos” and waits for a tap. Switching the sample to “wiht” demonstrates an automatic fix, while “Niah” demonstrates protection. Edit rule opens the matching dictionary entry and returns to the same example so you can check the result. A ruled dictionary keeps spellings and their fixes together. The navy voice panel reuses those same names in a sample transcript.

Cream #FFF3DE, navy #1E2A4A, typo red #F0483E, and green #1FA67A come from the app icon. Darker green carries small text. Georgia sets the words themselves, system sans sets controls, and monospace labels mark rules and model sizes. Shape and text distinguish the three rules even without colour.

Open the HTML directly. Wide screens show all three views together. Phone widths keep three destinations within thumb reach along the bottom. Try “silos,” add a protected name, change a shortcut, or simulate downloading a model to unlock its mic. Changes last for the current page session. All vocabulary, model downloads, and speech are samples. Sizes are illustrative, pending the actual model manifest.
