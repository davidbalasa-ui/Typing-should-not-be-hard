# Security Policy

TypeBetter is a keyboard. It sees everything you type, it holds the API keys you give it, and, if
you switch it on, it can read and write text in other apps. A way to report a problem privately
matters more here than it does for most apps.

## Reporting a vulnerability

**Please do not open a public issue for anything that could be used against someone's device or
data.** Use GitHub's private reporting on this repository instead:

> **[→ Security tab of this repository](https://github.com/davidbalasa-ui/Typing-should-not-be-hard/security)**

Useful in a report: what you did, what happened, the Android version and device, and the TypeBetter
version from *Settings → About*. A clear description of the mechanism is worth more than a working
exploit.

Fixes go into the next release. Only the latest release is supported.

## Upstream

TypeBetter is a fork of [Dictate Keyboard](https://github.com/DevEmperor/Dictate) by DevEmperor,
which is a fork of [FlorisBoard](https://github.com/florisboard/florisboard). If a problem also
affects Dictate itself, please report it to Dictate too, through
[its own security policy](https://github.com/DevEmperor/DictateKeyboard/security/advisories/new).
